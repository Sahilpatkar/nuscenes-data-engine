**Goal:** Per-event explanatory subgraphs exported from the live Neo4j graph, rendered with streamlit-agraph in the Scenario page's Phase-6 slot, with the flagship's Cypher count computed (not sourced) and its SQL parity asserted (spec: `docs/superpowers/specs/2026-08-20-demo-phase6-design.md`).

**Architecture:** `demo/subgraph_export.py` builds Cypher text (flagship verbatim-asserted against GRAPH.md), runs it through an injectable `run_query` (the real one wraps `graph/connection.read_query`), and assembles agraph-ready JSON (nodes/edges/path/meta) per event. `demo subgraphs` stages the JSONs under `data/demo_curation/graph_subgraphs/`; `demo build` copies+validates them (absent/present like semsearch) and upgrades `overview_metrics.flagship.cypher` to the computed value. The page renders agraph + a metadata/narrative panel.

**Tech Stack:** neo4j driver (existing), streamlit-agraph 0.0.45 (new; `app/demo/requirements.txt` + the `serve` extra), pandas, Streamlit AppTest. Strict mypy + ruff.

**Working branch:** `demo-phase-6` (exists; spec at c2cf0f4). One commit per task.

**Verified facts (do not re-derive):**
- Live schema (guard.graph_schema_prompt): `(Sample {token, timestamp})-[:AT_POSE]->(EgoPose {speed_mps, accel_long_min_mps2, is_hard_braking, can_speed_kmh, ...})`; `(Sample)-[:HAS_OBJECT]->(ObjectObservation {category, distance_to_ego_m, ego_rel_x, ego_rel_y, visibility, ...})-[:OF_CATEGORY]->(Category {name, group})`; `(Sample)-[:IN_SCENE]->(Scene {token, name, location, is_night, is_rain})-[:IN_LOCATION]->(Location {name})`; `(Sample)-[:NEXT {dt_us}]->(Sample)`. Category matching is on `group` ('pedestrian', 'bicycle', 'car'...). Keyframe Sample.token == `samples.parquet.sample_token` (NOT sample_data_token — events carry both columns).
- GRAPH.md's verbatim flagship Cypher (docs/GRAPH.md ~:221-225, fenced ```cypher) returns **30 live**. Extract it with the regex `r"```cypher\n(MATCH \(e:EgoPose \{is_hard_braking: true\}\).*?)```"` and strip `//` comments; the test asserts the exporter's flagship count query equals it modulo whitespace/comments.
- Graph access: `graph/connection.py::get_driver(settings)`, `read_query(driver, cypher, *, database, params?)` (READ its signature), `close(driver)`; `guard.run_cypher` is the read-only guarded runner used by chat — reuse `read_query` for the exporter (it is our own code, the queries are fixed text). Settings: `get_settings().neo4j_database`.
- Live-Neo4j test precedent: tests/test_graph.py ~:588-606 — `pytest.importorskip("neo4j")`, try get_driver + a trivial query, `pytest.skip` on any exception.
- Build seams: `build.py::_include_events` (:281), `_include_semsearch` (:365 — the absent/present pattern to mirror), call sites :498-499; `_PACKAGE_VERSION`; overview export `export_overview(..., flagship_cypher={"count", "source"})` — the computed switch happens in run_build AFTER the subgraph step by patching overview_metrics.json via `write_json` (the hero_token precedent).
- CLI demo commands: curate :1017, infer :1080, semsearch :1160, build :1218 — add `subgraphs` after semsearch, modelled on semsearch (lazy driver; unreachable → directive ValueError naming `docker compose up -d neo4j`).
- Staged events: `data/demo_curation/` does NOT hold scenario_events.parquet (the build computes events live). The exporter therefore recomputes the event list by calling `events.build_events(...)` with the same config (cheap, deterministic, 126 rows) — do not add a new staged events file.
