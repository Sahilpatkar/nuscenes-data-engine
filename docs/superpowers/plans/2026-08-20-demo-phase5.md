**Goal:** Preset driving-scenario queries over `scenario_events.parquet`, a synchronized event viewer with a t−2…t+2 filmstrip, and the recorded semantic gallery (spec: `docs/superpowers/specs/2026-08-20-demo-phase5-design.md`).

**Architecture:** A new pure module `src/nuscenes_data_engine/demo/events.py` computes per-keyframe dynamics/context features and applies six named preset predicates (thresholds in `configs/demo.yaml`); the flagship count is asserted == 30 before capping. `demo build` gains an events step (thumbs for events + filmstrip neighbors) and copies a staged semsearch parquet when present (produced by a new `demo semsearch` CLI, torch-local, mirroring the curation pattern). `views/scenarios.py` replaces the stub, reusing the Phase-3 renderer and session-state idioms.

**Tech Stack:** pandas/pyarrow, DuckDB-free (pure pandas joins), Streamlit + AppTest, lazy SigLIP for semsearch. Strict mypy + ruff; ValueError guards.

**Working branch:** `demo-phase-5` (exists; spec at 4302993). One commit per task.

**Verified facts (do not re-derive):**
- `data/processed/`: `canbus.parquet` (34,149 rows; `sample_token, is_hard_braking (bool|null — use .where(notna, False).astype(bool), the curate.py precedent), accel_long_min_mps2, can_speed_kmh`), `ego_pose.parquet` (`sample_token, speed_mps`), `annotations_3d.parquet` (`sample_token, category_group, distance_to_ego_m`), `samples.parquet` (`sample_data_token, sample_token, channel, scene_token, scene_name, timestamp, is_night, is_rain`). CAM_FRONT keyframes are 1:1 with canbus (34,149 = 34,149). 94 hard-braking rows. Category groups: car, truck, bus, pedestrian, bicycle (cyclist = `bicycle`).
- Flagship semantics (must reproduce 30): hard-braking sample_tokens with ≥1 pedestrian `distance_to_ego_m < 10` — the exact SQL is in `demo/exporters.py::FLAGSHIP_SQL`; the events computation must agree with it and the build asserts it.
- demo_data staging (`data/demo_curation/`): `frame_manifest.parquet` (125 val tokens; `split` col), `gt_boxes.parquet` (`matched_baseline` etc., `category_group`, `below_visibility_min`), `predictions.parquet` (`model, status, conf, sample_data_token`). Model presets read STAGING (not the committed demo_data) at build time, same as `_include_curation`.
- `demo/build.py`: `_include_curation` pattern (absent → warn + manifest note; partial → named error); `exporters.export_thumbs(lancedb_path, table, tokens, out_dir)` (all-or-nothing; tokens hex-validated); `write_json`; manifest input-hashing loops. `configs/demo.yaml` has `paths:`, `curation:`, `models:`, `hero:`, `budgets:`, `flagship:` sections.
- App side: `app/demo/render.py` `draw_overlay(image, gt, preds, *, mode, scale)` (gt needs a `matched` bool-ish col; NA→plain GT), `recorded_banner`; `app/demo/filters.py` pure module (AST test forbids backend imports — pandas only); `views/failures.py` session-state detail idiom (`st.session_state["failure_token"]`, buttons keyed per token); `data.py` cached loaders + `DEMO_DATA_DIR` env override; `views/stubs.py` still has `scenarios()`; `main.py` registers it.
- Baseline: 489 passed, 3 deselected. CI torch-free. The AppTest fixture (`tests/test_demo_app.py::built_demo_data`) builds a tiny package via `run_build` — Task 3 extends it with a tiny events parquet + thumbs.
- Thumb budget: ≤ ~180 events × ≤5 filmstrip tokens ≈ ≤900 thumbs ≈ 7 MB; package budget 100 MB (currently 20.06).
